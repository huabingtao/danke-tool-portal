## 2. 统一多平台 Frontmatter 元数据规范

所有弹壳攻略 Markdown 顶部统一采用以下**纯净对称**的 YAML 标准：

```yaml
---
title: "【活动攻略】[活动名称]轻松白嫖[核心奖励]！"
social_title: "[活动名称]轻松白嫖[核心奖励]！"
author: "弹壳呱呱"
date: 2026-08-12
lastmod: 2026-08-12
summary: "[活动名称]活动火热来袭！深度解析如何以最高性价比白嫖[核心奖励]，以及针对各开箱节点的钻石补充与兑换指南！"
cover: "./cover.png"
cover_vertical: "./cover_vertical.png"
tags:
  - 弹壳特攻队
  - 游戏攻略
  - [活动名称]
---
```

### 字段说明与回退逻辑

| 字段 | 必填 | 说明 | 兼容与回退逻辑 |
| :--- | :---: | :--- | :--- |
| `title` | **是** | 微信公众号/长文章标题 (≤64字) | — |
| `social_title` | 否 | 抖音/小红书短标题 (≤20字) | 若未填写，各社媒 Skill 自动截取 `title` 前 20 字 |
| `author` | 否 | 作者名字 | 默认 `弹壳呱呱` |
| `date` / `lastmod` | 否 | 创建与修改时间 | 默认当前日期 |
| `summary` | **是** | 摘要 / 社媒发布正文描述主体 | — |
| `cover` | 否 | 公众号横版封面图 (2.35:1) | 编译时兼容读取 `image` 字段，默认寻找同级 `cover.png` |
| `cover_vertical` | 否 | 社媒竖版封面图 (3:4) | 抖音/小红书优先将其作为第 1 张图片上传；若无则直接使用切图集 |
| `tags` | 否 | 话题/标签列表 | 在社媒正文末尾自动输出 `#标签1 #标签2` |
