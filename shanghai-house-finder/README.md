# 上海全景找房工作台 (`shanghai-house-finder`)

上海市二手房与新房可视化找房系统，围绕**总价区间/单价区间精准过滤**、**地图空间联动**、**高清户型图与房屋实拍图画廊**、**地铁/公交/自驾三维交通通勤测算**以及**周边四大生活配套（商超、医院、学校、公园）**构建。

## 核心功能

1. **多维价格与空间筛选**
   - 支持自定义输入或快捷筛选**房价区间（总价：万元）**与**单价区间（元/㎡）**。
   - 支持切换**全部 / 二手房 / 新房**、上海市 16 个行政区（浦东、徐汇、静安、黄浦、长宁、闵行、普陀、杨浦、虹口、宝山、嘉定、松江、青浦、奉贤、金山、崇明）、户型居室及排序规则。
2. **交互式找房地图 (`HouseMap`)**
   - 房源价格气泡聚合展示（二手房与新房分色标识）。
   - 选中房源自动渲染 **500m / 1km / 1.5km 生活圈同心圆**。
   - 周边配套分类彩色图钉（地铁站、公交站、商超、医院、学校、公园）及悬停距离提示。
   - 实时绘制从房源到目标通勤地点的**地铁、公交、自驾路线轨迹**。
3. **全景房源详情与画廊 (`HouseDetailDrawer`)**
   - **户型图**：CAD 1:100 建筑平面户型图（带毫米级开间进深尺寸标尺、指北针与各厅室面积）。
   - **房屋实拍图**：客厅、主卧、厨房、卫浴、小区园林外立面等多空间实拍画廊，支持全屏灯箱缩放。
   - **三维交通评估**：最近地铁站/公交站步行距离、自驾主干道/高架入口及车位比，以及到指定办公商圈的地铁/公交/自驾耗时、换乘路线与打车费用预估。
   - **周边四大生活配套 + 五维雷达评分**：周边商超、医院、学校、公园距离清单与宜居雷达图。
4. **定向爬虫控制台 (`CrawlerConsoleModal`)**
   - 支持按行政区、二手房/新房、总价段触发采集任务，并自动聚合周边 6 大类 POI 入库。

## 快速开始

```bash
# 1. 初始化/更新上海16区真实二手房与新房数据
npm run seed

# 2. 启动开发服务 (http://localhost:3088)
npm run dev

# 3. 运行自动化测试
npm run test
```
