## 一、 限时活动预算核算铁律 (`calculate_activity_budget.py`)

所有限时活动攻略（如时光拼图、海底探险、一番赏、幸运扭蛋、航海格子铺等）在撰写正文或制作抖音卡片前，**必须先构造 `活动数据.json` 并运行官方核算脚本**：

```bash
python3 /Users/hbt/skills/skills/danke-content-creator-skill/scripts/calculate_activity_budget.py \
  "文章目录/活动数据.json" \
  -o "文章目录/dist/数值核算.json" \
  --markdown "文章目录/dist/预算表.md"
```

### 1. 六大数学与事实边界铁律
1. **严禁虚构广告或未确认任务产出**：`tasks` 仅收录已确认的非开箱任务固定产出（如登录、主线、快巡、特别行动）。**未明确给出的每日广告道具一律不计入**；已确认的广告须单独标明条件。
2. **初始赠送与当前库存隔离**：`initial_items`（初始赠送）全期**只加 1 次**；截图中的「玩家当前背包剩余库存」或「测试已消耗数量」**绝不能叠加进全期免费收入**。
3. **开箱节点为累计值（禁止差额混用或线性插值）**：`box_rewards`（如 `{"400": 345, "500": 445, "600": 570}`）记录的是达到该开箱次数时的**累计获得道具总数**，不对未知开箱档位做线性插值。
4. **原始实测比例与取整方向**：
   - 设实测净消耗道具为 $C_{\text{sample}}$，实测净获进度差为 $P_{\text{sample}}$（注意是测试前后**进度差**，而非截图显示的累计总进度），道具单价为 $D_{\text{price}}$（钻石）。
   - **单道具期望进度**：$r = \frac{P_{\text{sample}}}{C_{\text{sample}}}$
   - **某开箱档位累计道具预计进度（四舍五入）**：$\text{Progress}_{\text{est}} = \text{round}\left(I_{\text{total}} \times \frac{P_{\text{sample}}}{C_{\text{sample}}}\right)$
   - **达成目标进度 $P_{\text{target}}$ 所需总道具数（向上取整）**：
     $$I_{\text{req}} = \left\lceil P_{\text{target}} \times \frac{C_{\text{sample}}}{P_{\text{sample}}} \right\rceil$$
   - **道具缺口与补钻预算**：
     $$\Delta I = \max(0, I_{\text{req}} - I_{\text{total}}), \quad \text{Diamonds} = \Delta I \times D_{\text{price}}$$
5. **进度必得奖励 vs 过程随机掉落严格分离**：
   - 每个方案开头必须写明完整累计进度奖励：`累计奖励：名称{{short}} ×数量、名称{{short}} ×数量。`
   - 局内随机掉落（如拼图过程偶发掉落的钥匙、核心）只能在活动介绍中作为「过程掉落」说明，**严禁混入档位必得的 `累计奖励`**。
6. **样本估算免责定性**：必须在正文中明确说明「按原始实测比例计算，道具需求向上取整，预计进度四舍五入；这是单次样本估算，并非保底；先领完任务用完道具，临近结束仍未达标再按实际缺口补钻」。

## 二、 标准 `活动数据.json` 结构与基准验算案例（时光拼图）

```json
{
  "initial_items": 5,
  "tasks": {"每日登录": 50, "主线章节": 65, "快速巡逻": 100, "特别行动": 97},
  "box_rewards": {"400": 345, "500": 445, "600": 570},
  "sample": {"items_consumed": 203, "progress_gained": 254, "source": "用户实测前后截图"},
  "item_price_diamonds": 100,
  "plans": [
    {"progress": 850, "cumulative_rewards": [{"name": "神器核心自选", "quantity": 1}], "source": "850档奖励"},
    {"progress": 1000, "cumulative_rewards": [{"name": "神器核心自选", "quantity": 1}, {"name": "月咏动态头像", "quantity": 1}], "source": "1000档累计奖励"},
    {"progress": 1650, "cumulative_rewards": [{"name": "神炼核心", "quantity": 1}, {"name": "神器核心", "quantity": 1}, {"name": "月咏动态头像", "quantity": 1}], "source": "1650档累计奖励"}
  ]
}
```

### 基准验算输出对照表（注意表头钻石单位规范）
- 非开箱任务 + 初始赠送 = `50 + 65 + 100 + 97 + 5 = 317` 个道具；600 箱全满总计 = `317 + 570 = 887` 个道具。
- 850 / 1000 / 1650 进度所需道具分别为：$\lceil 850 \times 203 / 254 \rceil = 680$、$\lceil 1000 \times 203 / 254 \rceil = 800$、$\lceil 1650 \times 203 / 254 \rceil = 1319$。

| 开箱次数 | 累计道具 | 预计进度 | 补至 850（钻石） | 补至 1000（钻石） | 补至 1650（钻石） |
| ---: | ---: | ---: | ---: | ---: | ---: |
| 400 | 662 | 828 | 1800 | 13800 | 65700 |
| 500 | 762 | 953 | 0 | 3800 | 55700 |
| 600 | 887 | 1110 | 0 | 0 | 43200 |

1. **第一梯队（稀缺核心与绝版）**：`神炼核心{{神炼核心}}` / `神器核心{{神器核心}}` / `特工觉醒核心{{觉醒核心}}` / `异宠核心{{异宠核心}}` / `谐振芯片{{谐振芯片}}` / 活动限定红藏品。
