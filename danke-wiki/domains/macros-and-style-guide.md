## 一、 弹壳呱呱内容创作与多端分发硬性规范

### 1. 正文道具配图规范（`完整名称{{short}}`）
- **标准写法**：正文中首次或关键位置提及道具时，采用 `完整名称{{short}}` 格式，例如 `科技滑板碎片{{滑板碎片}}`、`双绝枪{{双绝枪}}`、`S级杰出装备自选礼包{{S自选箱}}`。
- **严禁事项**：
  - 同一素材只使用下方速查表中唯一的标准 `{{short}}` 宏，不自己生造未收录的宏名；
  - 严禁因宏名简短而将正文里的中文道具名也缩写（如正文不能只写“S自选箱”，应写 `S级杰出装备自选宝箱{{S自选箱}}`）；
  - 缺失图标的新道具保留纯文字名称与数量，**严禁猜图或保留空图**。

### 2. 表格与数值排版规范
- **表格钻石单位统一归表头**：例如表头写 `补至 850（钻石）` 或 `钻石收益（钻石）`，**数据单元格只写纯数字**（如 `1800`、`0`），单元格内不重复写“钻”、“钻石”或 `{{钻石}}` 图标。正文叙述中的钻石单位正常保留。
- **每个方案必含累计奖励行**：格式固定为 `累计奖励：**道具名**{{short}} ×1、**道具名**{{short}} ×1。`

### 3. 封面制作规范（横竖双版同出）
- **默认双版本输出**：制作任何攻略封面时，默认同时输出 **横屏（公众号 2.35:1）** 与 **竖屏（图文 3:4）** 两个版本，保存至文章目录 `dist/cover.png` 与 `dist/cover_vertical.png`，并同步更新 Markdown frontmatter（`cover` / `cover_vertical`）与微信发布元数据。
- **日历专属共同封面**：每日提醒日历文章（`my-articles-md/提醒/YY.M.D/YY.M.D.md`）统一复用 `my-articles-md/提醒/日历系列封面/dist/cover_calendar_series.png`，并在每期将 **逃离行动、区域行动、联机挑战** 的玩法名称标红，文末固定推荐 3 篇往期攻略。

### 4. 微信排版与抖音深蓝电竞 3:4 图文交接规范
- **微信公众号编译与发布**：
  ```bash
  python3 /Users/hbt/skills/skills/danke-strategy-skill/scripts/interactive_flow.py \
    -y "文章目录/攻略.md" --pack /Users/hbt/skills/skills/danke-strategy-skill/packs/danke
  ```
- **抖音 3:4 图文卡片渲染与有头审核**：
  - 采用 **600×800 布局（2倍输出 1200×1600）** 深蓝电竞卡片，每个方案独立成卡并配真实道具图，长内容自动续页，不缩小字号、不截断表格行。
  - 上传抖音时**默认停在有头浏览器编辑页（`--headed --review`）供用户人工核对发布**，严禁点击发布/暂存，严禁将“上传就绪”谎报为“已发布”。
